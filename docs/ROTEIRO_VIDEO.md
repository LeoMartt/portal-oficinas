# Roteiro para o vídeo de apresentação (3 a 5 minutos)

O vídeo é um item obrigatório do trabalho. Use uma gravação de tela; não é necessário aparecer em câmera. Todos os dados demonstrados devem ser fictícios.

| Tempo sugerido | O que mostrar e explicar |
|---|---|
| 0:00–0:30 | Apresente o Instituto Sakura, o objetivo acadêmico e as tecnologias HTML, CSS, PHP e JSON. |
| 0:30–1:10 | Abra o catálogo, mostre as seis oficinas e os filtros por categoria. Use os checkboxes e limpe os filtros. |
| 1:10–2:10 | Clique numa oficina e mostre a pré-seleção. Envie uma inscrição válida e exiba a confirmação. |
| 2:10–2:45 | Tente repetir a inscrição ou enviar um dado inválido e mostre a rejeição. |
| 2:45–3:30 | Abra a listagem de inscrições, confira o total e mostre `dados/inscricoes.json` no VS Code. |
| 3:30–4:20 | Explique o caminho `inscricao.php` → `salvar-inscricao.php` → `armazenamento-inscricoes.php` → JSON e a diferença entre validação HTML e PHP. |
| 4:20–4:50 | Mencione a documentação, o GitHub, os testes e os principais usos de IA registrados no `USO_IA.md`. |

## Conferência antes de enviar

- [ ] Duração final entre 3 e 5 minutos.
- [ ] Som e gravação legíveis; nenhum dado pessoal verdadeiro exibido.
- [ ] Mostra catálogo, filtro, inscrição válida, rejeição e consulta dos registros.
- [ ] Explica as validações no servidor e como o JSON mantém os registros.
- [ ] Comenta decisões próprias e o apoio de IA, conforme `USO_IA.md`.
- [ ] Vídeo publicado com permissão de acesso ao professor.
- [ ] Link acrescentado ao `README.md` e aberto em janela anônima para testar o acesso.
